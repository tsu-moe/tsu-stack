# i18n

Add user-visible copy to [en.json](../packages/i18n/messages/en.json) using `feature_or_page__purpose`, for example `home_page__hero_title`. Edit other locales only for explicitly requested translation work.

- Resolve `m.*()` during render or request handling so SSR and hydration use the same locale. Keep deferred functions in long-lived config.
- The URL owns locale. Non-base locales have a path prefix and the base locale is unprefixed. Keep the strategy in URL-first, base-locale order. Use the localized Link and navigation provider instead of assigning locale directly.
- After adding or renaming keys, run `vp run --filter @tsu-stack/i18n build` when generated messages need updating. This compiles messages and fallback. Check the local and localized route when changing navigation.
- Root `dev`, `check`, and `fix` call `i18n:ensure`, which compiles only when a required entry point is missing. Keep the preflight before parallel dev scripts so the web app can resolve generated imports on a fresh clone.

See [Web routes](data-flow.md) and [SEO](seo.md) for locale-aware routes and metadata.
