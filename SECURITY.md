# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting form to report a vulnerability:

<https://github.com/tsu-moe/tsu-stack/security/advisories/new>

If private vulnerability reporting is unavailable, contact the maintainers through the
[tsu!moe GitHub profile](https://github.com/tsu-moe).

Include the affected version or commit, the impact, reproduction steps, and any proof of concept
needed to verify the report. Please avoid including real credentials or other sensitive data.
